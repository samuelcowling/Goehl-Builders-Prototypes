# Goehl Builders — Modern prototype

Open index.html in your browser to preview the selected homepage. No installation or build step is required.

The prototype uses the supplied black-and-gold logo, original homepage heading, and six project photos. The 3D gallery supports arrow buttons, keyboard navigation, drag or swipe, thumbnail selection, and automatic playback with a pause control. The contact form is a local demonstration and does not send messages.

The owner-managed gallery and production contact form are future work. Confirm the existing GoDaddy plan before choosing an implementation. The intended social feature is a link to the business's Facebook Page.
